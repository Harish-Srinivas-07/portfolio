## Reference Design (reference.png)
Minimalist single-page "terminal" style portfolio:
- Monospace font throughout, white bg, near-black text, orange (#f97316-ish) accent
- Fixed top-left logo mark: "// XX" initials, orange double-slash
- Hero: circular avatar, "Hey, I'm **Name**!" heading (name orange+underlined),
  short bio paragraphs (one w/ inline icon+bold keyword), two pill CTA buttons
  (dark filled primary w/ keycap icon, outline secondary w/ keycap icon),
  green-dot availability line
- Repeated section pattern: small uppercase gray label ("TECH STACK", "PROJECTS", etc.)
  + one-line intro sentence + content
- Tech stack: rounded-full gray pill badges, icon + label
- Projects: bordered rounded cards in a 2-col grid — icon, title, colored status badge
  (green=Active, amber=Sold-equivalent), description text
- Social links: pill badges row, icon + label
- Get in touch: underlined orange links (email, booking)
- Footer: copyright left, "open-source" link right, top border separator
- Content column ~760px, centered, generous vertical rhythm between sections
